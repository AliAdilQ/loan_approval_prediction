# Educational loan dataset

`loan_data.csv` contains 800 fictional records generated by `ml_workflow/dataset.py` with NumPy seed 42. It contains no real applicants or institutional lending decisions. Currency is USD; income is monthly, before tax; loan amounts are total principal.

| Column | Meaning / values |
| --- | --- |
| applicant_income | Monthly applicant income in USD |
| coapplicant_income | Monthly co-applicant income in USD, including zero |
| loan_amount | Requested principal in USD |
| loan_amount_term | 60, 120, 180, 240, 300, or 360 months |
| credit_history | 1 = good; 0 = poor |
| gender | Male / Female |
| married | Yes / No |
| dependents | 0 / 1 / 2 / 3+ |
| education | Graduate / Not Graduate |
| self_employed | Yes / No |
| property_area | Urban / Semiurban / Rural |
| Loan_Status | Approved / Rejected |

Labels are sampled from a probability derived from a noisy synthetic affordability profile. The generator uses assumptions about credit, repayment burden, education, employment, and dependents; these assumptions are illustrative and must not be treated as underwriting policy. Demographic fields are included for the requested demonstration and have not been audited for bias. About 2.5% of values in each of four predictor columns are intentionally missing to exercise imputation.

Training removes duplicate rows and missing targets. Imputation, scaling, and categorical encoding are fitted within each training fold. Model selection uses five-fold cross-validation on 640 records; the 160-record test split is used once for final evaluation. These synthetic metrics do not measure real-world performance. Model probabilities have not been calibrated.

Regenerate this exact sample with `python train_model.py --regenerate`. Running `python train_model.py` preserves an existing CSV and trains from it. Replacing the dataset with real data requires provenance, appropriate consent, schema validation, bias analysis, and new evaluation.
