# Third-party frontend assets

Assets are vendored so the application does not need external CDN requests at runtime.

| Library | Version | Source | License |
| --- | --- | --- | --- |
| Bootstrap | 5.3.8 | https://github.com/twbs/bootstrap | MIT, included in `static/vendor/bootstrap/LICENSE` |
| Bootstrap Icons | 1.13.1 | https://github.com/twbs/icons | MIT, included in `static/vendor/bootstrap-icons/LICENSE` |

The visual design, templates, and custom styles are original project code. The favicon is an original SVG.
