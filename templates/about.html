Loan Approval Prediction is a machine-learning powered web application developed to demonstrate the integration of predictive analytics with a modern Django web application.

Explore on GitHub
THE WORKFLOW

A complete path from data to decision.

  1. 01

    Sample data & preprocessing

    800 reproducible, fictional applications. Missing values are imputed; numeric features are scaled and categories are one-hot encoded inside one fitted pipeline.

  2. 02

    Machine learning

    Logistic Regression, Random Forest, and Decision Tree are compared using five-fold cross-validation. The selected model is evaluated on a separate 20% test set.

  3. 03

    Django integration

    Validated form data reaches a dedicated inference service. The trained model returns a class and its estimated probability.

  4. 04

    Application history & Django Admin

    SQLite stores every successful prediction. Staff can search, filter, edit, and manage applications using Django Admin and the application dashboard.
